## MineXray 1.0.0 (Minecraft 1.21.1, Fabric)

MineXray on its own: the X-ray and ESP tab from MineMeBoostXray as a separate mod, for people who only want MineXray. **Right Shift** opens it. Like the MineMenu cheats, it only works in singleplayer and in LAN worlds you host. On a multiplayer server every mode is off and nothing is scanned or sent.

### Modes

Several can be on at once, each with its own key (Options > Controls > Key Binds > MineXray):

- **Classic X-Ray** (key **X**): only the preset's *Visible* blocks stay drawn, with full brightness while it's on. Hidden blocks can be see-through (0-100%). Not available with Sodium; use Ore ESP there.
- **Ore ESP** (key **G**): the preset's blocks through walls. Touching blocks show as one vein. Labels ("Diamond Ore ×6 · 14m"), tracers to the nearest veins, 4 styles, radius 8-128.
- **Cave Finder**, **Fluid View**, **Lava Warning**, **Block ESP** (chests, spawners, vaults, portals, amethyst, suspicious sand, sculk, redstone, infested blocks) and **Entity ESP** (mobs by type).

### Tools

- **Block editor:** every block in the game, including modded ones, plus tags. Deepslate ores share the normal ore's line.
- **Presets:** 9 built-in, switching per dimension. Save, rename, duplicate, delete, and share as a code.
- **Scanner:** every vein within 128 blocks. Show it for 30 s, teleport next to it, or mine it whole.
- **HUD:** Ore Counter, Nearest Ore Arrow, Y-Level Guide, Session Stats.

### What MineMeBoostXray adds

Inside MineMeBoostXray, MineXray also gets:

- MineMenu's waypoints, themes, minimap, Command Palette and profiles;
- MineBoost's FPS Target and the A/B cost test.

On its own, the waypoint and cost-test buttons are greyed out.

### Install

Fabric Loader for 1.21.1 + Fabric API, then `MineXray-1.0.0.jar` in `mods`. **Don't use it together with MineMeBoostXray**, which already contains MineXray; Fabric refuses to start with both. Settings: `config/minexray/`.
