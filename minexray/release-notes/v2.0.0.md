## MineXray 2.0.0 (Minecraft 1.21.1, Fabric)

### New: multiplayer servers

MineXray can now also run on multiplayer servers. It stays **off** until you switch on **Settings > Allow on servers**; the button asks for a second click and explains the risks.

- **Use it only where X-ray is allowed.** Many servers forbid it and you can be banned. Servers with anti-xray hide ores or send fake ones, so ESP may show nothing or the wrong blocks.
- **What works on servers:** every mode, the scanner list (with Show), presets, the HUD and labels, all on your computer only. MineXray never sends anything to the server.
- **What stays off on servers:** Teleport and Mine whole vein, which change your own world.

### Install

Fabric Loader for 1.21.1 + Fabric API, then `MineXray-2.0.0.jar` in `mods` (remove older `MineXray-*.jar`). Not together with MineMeBoostXray, which already contains MineXray. Settings: `config/minexray/`.
