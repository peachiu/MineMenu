## MineMeBoostXray 4.0.0 (Minecraft 1.21.1, Fabric)

### New: MineXray on multiplayer servers

MineXray can now also run on multiplayer servers. It stays **off** until you switch on **MineXray > Settings > Allow on servers**; the button asks for a second click and explains the risks.

- **Use it only where X-ray is allowed.** Many servers forbid it and you can be banned. Servers with anti-xray hide ores or send fake ones, so ESP may show nothing or the wrong blocks.
- **What works on servers:** Classic X-Ray, Ore ESP, Block ESP, Entity ESP, Cave Finder, Fluid View, Lava Warning, the scanner list (with Show), presets, the HUD and labels. Everything runs on your computer only; MineXray never sends anything to the server.
- **What stays off on servers:** Teleport, Mine whole vein and waypoints (they change your own world), and MineMenu's cheats, which are still singleplayer-only.
- With the option off, nothing changes from 3.6: on servers MineXray scans and draws nothing.

### Also in 4.0

- New icon with all three parts (M, bolt, X).
- MineXray is also its own mod (MineXray 2.0.0). Don't install both.
- MineXray's code now lives in its own folder and connects to MineMenu and MineBoost through a small bridge; nothing changes for you.

### Install

Fabric Loader for 1.21.1 + Fabric API, then `MineMeBoostXray-4.0.0.jar` in `mods`. Remove older `MineMeBoostXray-*.jar`, `minemeboost-*.jar`, `minemenu-*.jar`, `mineboost-*.jar` and `MineXray-*.jar`. Your settings stay.
