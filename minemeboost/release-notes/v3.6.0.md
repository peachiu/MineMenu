## MineMeBoostXray 3.6.0 (Minecraft 1.21.1, Fabric)

MineMeBoost is now **MineMeBoostXray**: a third tab, **MineXray**, joins MineMenu and MineBoost. The mod id is still `minemeboost`, so your settings, worlds and keys stay as they are. Like MineMenu's cheats, MineXray only works in singleplayer (and LAN worlds you host); on a multiplayer server every mode is off and nothing is scanned or sent.

### New: MineXray

Several modes can be on at once, each with its own key (Options > Controls > Key Binds > MineXray):

- **Classic X-Ray** (key **X**): only the preset's *Visible* blocks stay drawn, with full brightness and no smooth-lighting shadows while on. Hidden blocks can be shown see-through (opacity 0-100%). Chunks are rebuilt once per switch or list change ("Rebuilding chunks..."), and everything is put back when you switch it off. Not available with Sodium; use Ore ESP there.
- **Ore ESP** (key **G**): the preset's blocks through walls, without rebuilding chunks. Touching blocks of the same kind are drawn as one vein. Outline, filled box, outline + fill or corners only; colour per block, line thickness, opacity, fade with distance, tracers to the nearest veins, labels ("Diamond Ore ×6 · 14m"), radius 8-128, block limit (nearest first).
- **Cave Finder**: caves and ravines below a height you choose, as dots or an outline; optionally only large ones.
- **Fluid View**: lava (and optionally water) through walls.
- **Lava Warning**: a warning and a sound when there's lava up to 3 blocks behind or under the block you're mining.
- **Block ESP**: storage, spawners, vaults, portals, budding amethyst, suspicious sand/gravel, sculk, redstone, infested blocks; a switch and a colour per category.
- **Entity ESP**: mobs through walls, coloured by type (hostile, passive, players, items). It replaces Mob Glow.

Plus:

- **Block editor:** every block (modded too) with search, icon, name and id. Add blocks by search, by looking at them, from your hand, or as a tag. Deepslate ores follow the normal ore.
- **Presets:** 9 built-in (All Ores, Diamonds Only, Netherite Hunt, Gold & Emerald, Redstone & Lapis, Caves, Structures, Ancient City, Clean Classic). Save, rename, duplicate, delete, share as a code. Automatic switch per dimension.
- **Scanner:** "Scan now" lists every vein within up to 128 blocks, without freezing the game. Per vein: mark as waypoint, show for 30 s, teleport next to it, mine it whole.
- **HUD:** Ore Counter, Nearest Ore Arrow, Y-Level Guide, Session Stats, active modes; veins on the minimap.
- **Integrations:** Freecam, Command Palette ("xray diamonds"), favourites, keys and profiles.
- **Performance:** background scanning per section with a palette check first, a per-section cache, GPU buffers per 64-block region (a few draw calls per frame), near and on-screen first, Adaptive range below your FPS Target, a capped cache, and nothing at all when every mode is off. *Settings > Measure the cost (A/B)* measures each mode on your PC.

### Changed

- MineMenu's **Ore Vision, Chest ESP and Mob Glow** are now shortcuts that switch on Ore ESP, Block ESP and Entity ESP. Their on/off state, radius and any key you gave them carry over. Mob Glow no longer uses the Glowing effect on the server.
- The A/B tool can now run other mods' tests (MineXray uses it for its cost test).

### Fixed

- Boxes drawn in the world (build selection, paste preview, slime chunks, light levels) were rotated twice and drifted off their blocks when you looked up or down.
- The in-game test run on CI started without its prepared old config files (they were never committed), so two migration checks failed.

### Install

Fabric Loader for 1.21.1 + Fabric API, then `minemeboost-3.6.0.jar` in `mods`. Remove `minemenu-*.jar` and `mineboost-*.jar` if you have them.
