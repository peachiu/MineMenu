MineMeBoost 3.0.3 for **Minecraft Java 1.21.1** (Fabric): fast mining while flying, and Enable All.

## Fixed: mining while flying

Minecraft makes you mine **5× slower** whenever your feet aren't on the ground, so with **Fly** on, breaking blocks in the air was painfully slow. Now, while Fly is on, you mine in the air exactly as fast as on the ground. (Without Fly, Minecraft's normal rule is unchanged.)

## New: Enable All / Disable All

A new button in the MineMenu tab's bottom row, next to Done:

- **Enable All** turns every ON/OFF hack on at once, on all four pages.
- The button then changes to **Disable All**, which turns them all off again.
- Show HUD, Show FPS and Size aren't changed.

## Install

1. Install the [Fabric Loader](https://fabricmc.net/use/installer/) for Minecraft **1.21.1**.
2. Put [Fabric API](https://modrinth.com/mod/fabric-api) (1.21.1) and **`minemeboost-3.0.3.jar`** (below) in your `.minecraft/mods` folder. Remove the old `minemeboost` jar, and any `minemenu-*.jar` or `mineboost-*.jar`.
3. Join a singleplayer world and press **Right Shift**.

See the [MineMeBoost README](https://github.com/peachiu/MineMenu/blob/minemeboost-v3.0.3/minemeboost/README.md) for everything it does.
