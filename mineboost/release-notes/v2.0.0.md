MineBoost 2.0.0 for **Minecraft Java 1.21.1** (Fabric): Smart Render Distance, Max Particles and a benchmark.

## New

- **Smart Render Distance (FPS Target):** pick 30, 45, 60, 75, 90, 120 or 144 FPS. When the game drops below it, MineBoost lowers your render distance; when there's FPS to spare it raises it again, never above the distance you chose and never below 4. Render distance is the setting with by far the biggest effect on FPS.
- **Max Particles:** cap particles at 250, 500, 1000, 2000 or 4000, so TNT chains and big farms don't tank your FPS.
- **Benchmark (10s):** a button next to Done. It measures your FPS for 10 seconds and posts the average, 1% low and worst frame in chat. Try it with different presets.
- With Smart Render Distance on, the FPS overlay also shows the current render distance.

## Install

1. Install the [Fabric Loader](https://fabricmc.net/use/installer/) for Minecraft **1.21.1**.
2. Put [Fabric API](https://modrinth.com/mod/fabric-api) (1.21.1) and **`mineboost-2.0.0.jar`** (below) in your `.minecraft/mods` folder. Remove the old `mineboost` jar.
3. Join a world and press **`.`**.

Want MineMenu too? Get **MineMeBoost 3.0.0** instead (don't install both).
