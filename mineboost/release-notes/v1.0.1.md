MineBoost 1.0.1 for **Minecraft Java 1.21.1** (Fabric) fixes a bug in the menu.

## Fixed

- **Clicking a preset stacked a second copy of the menu on top of the first.** After a few clicks the text overlapped, several presets showed a ✔ and sliders were drawn twice. Now the menu refreshes cleanly: one ✔, on the preset you picked, and your scroll position is kept.

## Install

1. Install the [Fabric Loader](https://fabricmc.net/use/installer/) for Minecraft **1.21.1**.
2. Put [Fabric API](https://modrinth.com/mod/fabric-api) (1.21.1) and **`mineboost-1.0.1.jar`** (below) in your `.minecraft/mods` folder. Remove `mineboost-1.0.0.jar`.
3. Join a world and press **`.`**.

Want MineMenu and MineBoost together? Get **MineMeBoost** instead (don't install both).
